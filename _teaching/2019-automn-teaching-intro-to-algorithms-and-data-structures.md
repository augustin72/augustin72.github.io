Sumamry
=
The course unit provides cross-disciplinary knowledge in the following areas:

* Develop resolution algorithms and choose appropriate data structures
* Evaluate algorithmic complexities, both temporal and spatial
* Study different algorithms and data structures (arrays, linked lists, stacks, queues, binary search trees, graphs, sorting, hash codes)
* Implement in a given programming language (C)

Audience
==
Third year undergraduate

Duration
==
1 semester
